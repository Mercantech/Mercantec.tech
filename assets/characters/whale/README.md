# Docker, havnekaptajnen

Docker er arbejdsnavnet for LUPs gamle pukkelhval. Det valgte portræt og de tre hobbybilleder er bevaret som originale PNG-filer. Portrætudtrykkene blev lavet med den indbyggede ImageGen med den valgte havnekaptajn som reference.

Kaptajnens oprindelige portræt findes i `web/wwwroot/images/characters/whale/portrait.png`. Andre billeder bruger de samme karaktertræk og den malede stil. PNG-filerne i gallerierne bruges til download. WebP-filerne bruges til forhåndsvisning.

Infografikkerne kobler hvert emne til en eller flere af DevNets syv målpinde. Faglige kilder står i de enkelte billeders forklaringer. Docker er teknologien i undervisningen og arbejdsnavnet på den fiktive figur.
