# Gummianden

VATeks officielle appikon er kopieret uændret som `portrait.png` den 9. november 2026.

- Kildeside: https://gummianden.vatek.dk/info
- Originalfil: https://gummianden.vatek.dk/assets/assets/logo.png
- Format: PNG, 714 × 714 px.
- SHA256: `0a420943c0bbbdb04380c6fb2e60ee6f79780fddb7e0a9bc762d371ddbe6ecd8`
- Ophav: Videnscenter for Automation og Teknologi (VATek).

De fem WebP-portrætter er LUPs illustrationer af den gule gummiand. Lyttemakkeren er profilens første portræt. VATeks ikon kan stadig vælges fra portrætvælgeren.

Portrætfilerne er 768 × 768 px. Kilder, prompts og øvrige billedmaterialer er beskrevet i `assets/characters/gummianden/`.
