# Raymonds lydfiler

28 originale, varme og organiske lydeffekter samt fem lokale danske talereplikker. Se `audio-manifest.json` for ID, tekst, varighed og afspilningsregler. Alle 33 filer er mono PCM16 WAV ved 44.100 Hz, uden klipning eller dublerede bølgeformer.

Platformens replikker er genereret med dansk Røst Chatterbox og en syntetisk stemmereference med Raymonds dybe, rolige klang. Se `speech-provenance.json` for modelrevision, stemmereference og WAV-hashes. Den arkiverede workspace-pakke `design/raymond-avatar-v2/audio/` indeholder den oprindelige Microsoft Helle-stemme, demoer og cuefiler.
