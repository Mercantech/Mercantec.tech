# Raymonds lydfiler

28 originale, varme og organiske lydeffekter samt fem lokale danske talereplikker. Se `audio-manifest.json` for ID, tekst, varighed og afspilningsregler. Alle 33 filer er mono PCM16 WAV ved 44.100 Hz, uden klipning eller dublerede bølgeformer.

Rå talefiler, fuldt demo-montage, cuefiler, signalvalidering og browserafkodningskontrol ligger i workspace-pakken `design/raymond-avatar-v2/audio/`. Reproducerbare scripts ligger i repositoryet under `assets/avatars/raymond/scripts/audio/`. Tale er lokal Windows OneCore/Microsoft Helle med lavere varm karaktertone (pitch 0,86), rolig talehastighed 0,97 og mild EQ; ingen robotfilter, API eller stemmekloning.
