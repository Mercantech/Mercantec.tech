# Feature-planlægning

## Hvornår

Når vi skal beskrive eller designe en ny feature før kode.

## Prompt

```
Læs obsidian/00-home/Start her.md, Platform-vision og Stack-og-hosting.
Lav en plan for feature: <NAVN>.
Følg Feature-plan-skabelonen i obsidian/99-templates/Feature-plan.md.
Ingen kode endnu — kun plan, afhængigheder, risks og acceptkriterier.
Svar på dansk.
```

## Output

Plan der kan godkendes i Cursor Plan mode; opdater [[Feature-oversigt]] når feature er vedtaget.
