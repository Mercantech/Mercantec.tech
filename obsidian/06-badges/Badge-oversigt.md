# Badge-oversigt

Samlet katalog over badges på Mercantec.tech: hvad de betyder, hvordan de hænger sammen, og hvor design ligger.

## Sådan bruger vi mappen

| Sti | Indhold |
|-----|---------|
| Denne note | Liste + status over alle badges |
| [[Emne-badges]] | Custom badges pr. emne + fem niveauer |
| [[Sammenhæng]] | Træer, forudsætninger, XP/quest-koblinger |
| `katalog/` | Én note pr. badge (brug skabelon [[Badge]]) |
| `design/` | Artwork, mocks, referencer (KASC) |

## Emne-niveauer (alle emne-badges)

| Niveau | Krav (kort) |
|--------|-------------|
| Lille | Forklare om emnet |
| Mellem | Fremlægge klasseprojekt om emnet |
| Stor | Fremlægge eget projekt for læreren |
| Mega | Fremlægge for klassen |
| Ultra mega | Holde oplæg og undervise om emnet |

Detaljer: [[Emne-badges]].
