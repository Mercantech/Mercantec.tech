# Logbog

## Problem

Elever har brug for et sted til løbende refleksion; undervisere skal kunne følge med.

## Forslag

Logbog pr. elev (typisk i forløbs-/hold-kontekst): egne noter + refleksion. Kan give XP. **Synlig for underviser** (ikke privat notesbog).

## Acceptkriterier

- [ ] Elev kan skrive logbogsindlæg
- [ ] Underviser kan se elevens logbog
- [ ] Valgfri XP-regel ved indlæg (kobles til [[Levels-XP-Badges]])
