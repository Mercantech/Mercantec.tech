# Social portfolio

## Problem

Projekter skal kunne få feedback og interaktion uden at blive en generel chat-/beskedplatform.

## Forslag

Portfolio-stil: kommentarer og reaktioner på **projekt-kort**. Underviser-feedback på **afleveringer** forbliver privat (se [[Afleveringer]]).

## Acceptkriterier

- [ ] Kommentar på projekt
- [ ] Simpel reaktion (fx like) på projekt
- [ ] Synligt for dem der kan se projektet (åbent galleri)

## Afhængigheder

- [[Projekter-Steam-galleri]]
- [[Notifikationer]]

## Risks

- Uønsket peer-adfærd → moderering/rapportering senere

## Out of scope

- Fuld socialt netværk / chat
- Offentlig feedback på skoleafleveringer
