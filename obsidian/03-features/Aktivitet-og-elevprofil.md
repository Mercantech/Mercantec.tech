# Aktivitet og elevprofil

## Problem

Elev og underviser skal kunne følge aktiviteter; peers skal ikke kunne stalk’e hinandens fulde tidslinje.

## Forslag

- Elev ser **egen** aktivitetstidslinje
- Underviser kan åbne elev og se dennes aktiviteter
- **v1:** ikke delt på tværs af elever (ingen peer-feed af andres fulde aktivitet)

## Acceptkriterier

- [ ] Elevprofil med egen aktivitet
- [ ] Underviser kan se elevaktivitet for holdets elever
- [ ] Peer kan ikke se anden elevs fulde aktivitetstidslinje i v1
