# Onboarding-modal

## Problem

Nye brugere (og nye hold) har brug for en styret start uden en stiv engangs-wizard.

## Forslag

Konfigurerbar **onboarding** (modal/flow) ved opstart / start på hold. Indhold kan justeres løbende af underviser/admin.

## Acceptkriterier

- [ ] Onboarding kan vises ved første login / start på hold
- [ ] Indhold/trin er konfigurerbare (ikke hardcodet forever)
- [ ] Kan skips/afsluttes uden at låse brugeren ude af platformen

## Risks

- For mange obligatoriske trin → drop-off
