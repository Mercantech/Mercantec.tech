# Fritlagte karakterportrætter

De tre portrætter er fritlagt med det indbyggede image_gen-værktøj (background-extraction). Originalerne er bevaret. De valgte resultater er gemt som WebP med ægte alpha ved højst 680 px til visning på både Om LUP og Karakterer-siden.

| Karakter | Projektfil |
| --- | --- |
| Gummianden | web/wwwroot/images/characters/gummianden/portrait-transparent.webp |
| Kamæleonen | web/wwwroot/images/characters/chameleon/portrait-transparent.webp |
| Docker | web/wwwroot/images/characters/whale/portrait-transparent.webp |

Den fulde prompt for hver redigering og kilderne findes i prompts.json. Portrætvalget er samlet i CharacterCatalog via Portrait/DisplayPortrait.
